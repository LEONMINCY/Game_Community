# 面向游戏玩家的综合型游戏社区平台

一个面向游戏玩家的综合型游戏社区平台，覆盖社区发帖、新闻资讯、游戏中心、榜单排行、私信社交、AI 助手、支付订单、举报审核、后台管理和社区审核员工作台等完整业务链路。项目采用前后端分离架构，前台偏玩家社区体验，后台偏内容治理和运营管理，整体目标是让用户能够围绕游戏进行浏览、购买、评价、讨论、收藏、举报、私信和智能问答。

## 项目概述

本项目不是单一论坛或单一游戏商城，而是将“游戏内容社区 + 游戏资料库 + 游戏购买流程 + 社交通知 + 内容审核 + AI 助手”组合到同一个系统中。普通游客可以浏览公开内容，登录用户可以参与互动、购买游戏和管理个人内容，社区审核员负责新闻、帖子和举报处理，管理员拥有更完整的后台运营权限。

系统主要支持以下场景：

- 玩家查看游戏、筛选游戏、浏览折扣、加入购物车或愿望单并完成支付。
- 玩家围绕具体游戏发布帖子、评论、回复、点赞、收藏、转发和举报。
- 玩家查看新闻资讯，并对新闻进行点赞、收藏、评论、转发和评论举报。
- 玩家通过站内私信交流，支持文字、图片、表情和自定义表情包。
- 玩家通过站内通知查看点赞、回复、@我的、关注、举报进度等消息。
- 玩家在个人中心管理资料、签到、每日任务、动态、收藏、拥有游戏、订单、隐私和黑名单。
- 管理员和社区审核员在后台完成内容审核、举报处理、私信沟通、订单退款审核、日志追踪和数据分析。
- AI 助手可以围绕游戏攻略、社区帖子、新闻和站内数据进行问答，也能在评论区被 @ 后自动回复。

## 技术栈

### 前端

- Vue 3：前台、后台和用户中心页面的核心框架。
- Vite 6：前端开发服务器和生产构建工具。
- Vue Router 4：前台、后台、详情页、搜索页和登录页路由管理。
- Pinia：用户登录态、用户资料和跨页面状态管理。
- Element Plus：表单、表格、弹窗、分页、上传、按钮、标签和后台管理组件。
- ECharts 5：首页、后台首页、榜单模块、游戏详情页等可视化图表。
- WangEditor 5：帖子和新闻富文本编辑，支持图片、视频和格式化内容。
- Axios：统一封装前后端 HTTP 请求。
- Less：局部页面样式和复杂布局样式维护。

### 后端

- Spring Boot 2.5.4：后端应用基础框架。
- Spring MVC：REST API、参数接收和统一响应。
- Spring Security：登录认证、接口鉴权和 JWT 过滤。
- JWT：前后端分离状态下的登录令牌。
- MyBatis-Plus 3.4.2：实体映射、通用 CRUD、分页查询和 Mapper 扩展。
- MySQL 8：核心业务数据存储。
- Redis：热点数据缓存、验证码缓存、会话/消息辅助缓存、榜单缓存和性能优化。
- Redisson：分布式锁，处理订单、支付和高并发下的幂等场景。
- WebSocket：站内私信、通知推送和消息实时刷新。
- Java Mail：QQ 邮箱验证码发送，用于忘记密码找回。
- Alipay SDK：支付宝沙箱扫码支付、支付查询、退款等能力。
- MiniMax API：游戏社区 AI 助手和评论区 AI 自动回复。
- EasyExcel：后台日志和数据导出。
- Swagger / Knife4j：后端接口文档和调试入口。
- Hutool、FastJSON、ZXing、Lombok、Apache Commons：工具类、JSON、二维码、模板代码简化和通用处理。

### 运行环境

- JDK：推荐 JDK 17。
- Node.js：推荐 Node 18+。
- MySQL：推荐 MySQL 8.x。
- Redis：本地可使用 Windows Redis，项目已支持 Redis 连接配置。
- Maven：用于构建后端多模块项目。

## 功能模块

### 1. 用户与认证模块

用户体系支持游客访问、普通用户、社区审核员和管理员。游客可以浏览社区、新闻和游戏公开信息；涉及发布、评论、购买、收藏、私信、举报等写操作时需要登录。

子功能：

- 用户注册：支持用户名、手机号、密码、性别和年龄等信息，手机号按中国大陆 11 位规则校验。
- 用户登录：支持用户名或手机号登录，手机号登录依赖用户资料中已绑定手机号。
- 忘记密码：通过 QQ 邮箱发送验证码，校验验证码后重置密码。
- 密码加密：后端使用 Spring Security 体系进行认证和密码安全处理。
- JWT 登录态：前端保存令牌，后端通过过滤器识别当前用户。
- 游客访问：路由守卫允许游客浏览公开页面，写操作自动跳转登录。
- 角色区分：普通用户进入前台，社区审核员和管理员进入后台。
- 封禁拦截：账号封禁后限制登录，并保留申诉/沟通能力的业务入口设计。

### 2. 社区中心模块

社区中心是玩家围绕游戏交流的核心模块，支持内容发布、互动、搜索和治理。

子功能：

- 帖子列表：按推荐、游戏标签、话题、搜索关键词展示帖子。
- 热门社区：按游戏相关发帖数展示热门社区 TOP。
- 发布帖子：支持标题、富文本内容、封面、关联游戏、话题和多媒体内容。
- 话题系统：发布内容时可使用 `#` 关联自定义话题。
- 游戏标签：帖子可绑定游戏，详情页游戏标签可点击跳转到对应社区列表。
- 帖子详情：展示作者、等级、发布时间、编辑时间、游戏标签、正文和媒体内容。
- 点赞收藏：帖子详情和列表均支持点赞、取消点赞、收藏和取消收藏。
- 转发分享：支持转发给关注的人、生成复制链接并统计转发次数。
- 评论系统：支持评论、回复、图片、表情、表情包和评论排序。
- 评论点赞：评论和回复可点赞或取消点赞，并支持按最多点赞排序。
- 评论排序：支持默认、最新和最多点赞三种排序方式。
- @用户：评论区输入 `@` 可选择关注的人，被 @ 用户会收到通知。
- @AI助手：评论区 @AI 助手后，AI 会结合帖子内容和评论内容自动回复。
- 举报评论：可举报帖子评论，填写原因和证据后同步到后台举报管理。
- 审核机制：用户发布帖子后需后台审核通过才公开展示。
- 申诉机制：帖子审核拒绝后，用户可在“我的帖子”中发起申诉。

### 3. 游戏中心模块

游戏中心承担游戏资料展示、筛选、购买和评价入口。

子功能：

- 游戏列表：以卡片或列表形式展示游戏封面、名称、开发商、类型、评分、价格和折扣。
- 游戏搜索：支持按游戏名称、开发商、评分区间和评价类型筛选。
- 类型筛选：后台自定义游戏类型，前台按类型标签筛选。
- 平台筛选：支持 PC、PS5、Switch、Xbox 等平台标签，也支持后台自定义平台。
- 评分区间：按用户评分范围筛选游戏。
- 评价类型：按好评如潮、特别好评、好评、多半好评、褒贬不一、多半差评、差评、特别差评、差评如潮、暂无用户评测筛选。
- 限时优惠：独立入口展示正在打折的游戏。
- 折扣展示：后台设置折扣后，前台同步展示折后价、原价和折扣比例。
- 价格标记：支持史低、平史低和正常价，前台同步展示。
- 免费开玩：价格为 0 的游戏前台展示“免费开玩”，购买时直接成功，不进入扫码支付。
- 游戏详情：展示游戏简介、开发商、发售日期、平台、类型、价格、截图、视频和系统要求。
- 媒体预览：支持多张截图和多个视频，视频缩略图带视频标识。
- 愿望单：用户可加入或取消愿望单，已购买游戏不再展示愿望单按钮。
- 购物车：用户可加入或取消购物车，多款游戏可合并结算。
- 立即购买：付费游戏进入支付宝沙箱扫码支付流程。
- 游戏评价：已购买用户可发表评测，支持推荐、不推荐和默认中评。
- 评价分页：玩家评价支持分页和每页条数选择。
- 数据可视化：游戏详情展示评分数、评分趋势、好评率、总销量、月销量趋势等图表。

### 4. 榜单模块

榜单模块用于从销量、好评、愿望单、折扣和平台维度观察游戏表现。

子功能：

- 热销游戏榜：按收入排名，支持总榜、年榜、月榜和周榜。
- 游戏好评榜：按好评率排名，展示好评和差评占比。
- 最受期待榜：按愿望单数量排名，支持 Top10 横向条形图。
- 优惠促销榜：展示当前打折游戏的销量排名。
- 平台榜单：按 PC、PS5、Switch、Xbox 等平台统计游戏表现。
- 类型筛选：所有榜单均支持按游戏类型筛选。
- 排名分页：榜单默认展示前 100，超过范围可查看更多。
- 排名变化：展示与上一周期相比的排名变化和新上榜标识。
- 多维图表：使用柱状图、折线图、饼图、雷达图、热力图、矩形树图等展示榜单数据。
- Redis 缓存：榜单适合缓存，减少高频统计查询对 MySQL 的压力。

### 5. 搜索模块

全局搜索用于在首页顶部统一检索站内内容。

子功能：

- 搜索下拉：点击搜索框展示社区热榜、热门游戏和热门话题。
- 搜索历史：记录当前用户输入过的搜索关键词。
- 搜索结果页：输入关键词回车后进入独立搜索页面。
- 内容搜索：按帖子标题、正文和话题搜索社区内容。
- 游戏搜索：按游戏名称、类型、开发商等关键词搜索游戏。
- 用户搜索：支持按用户名和昵称搜索用户。
- 话题搜索：按话题关键词聚合相关内容。
- 结果跳转：搜索结果可跳转到帖子详情、游戏详情或用户主页。
  
### 6. 新闻中心模块

新闻中心用于发布和浏览游戏资讯、社区公告和行业内容。

子功能：

- 新闻列表：展示新闻标题、摘要、封面、发布时间和浏览量。
- 新闻详情：展示新闻正文、作者、发布时间、浏览数和多媒体内容。
- 新闻浏览量：进入新闻详情后累计浏览量。
- 新闻评论：支持评论、回复、表情、图片和评论举报。
- 新闻互动：支持点赞、收藏和转发。
- 新闻收藏：收藏后的新闻进入个人中心“我的收藏”新闻列表。
- 后台审核：管理员和社区审核员可管理新闻内容。
- 新闻评论治理：新闻评论可进入举报管理流程。

### 7. 站内私信模块

站内私信用于玩家之间、用户与审核员之间、审核员与管理员之间沟通。

子功能：

- 会话列表：展示已有聊天记录的用户，不直接列出所有用户。
- 实时消息：通过 WebSocket 推送新消息，减少刷新依赖。
- 未读提醒：消息中心旁显示未读红点和未读数量。
- 会话未读：进入消息中心后，未读会话旁显示未读标记。
- 文本消息：支持普通文字私信。
- 表情消息：复用评论区/聊天区统一表情列表。
- 图片消息：支持发送本地图片。
- 自定义表情包：支持用户维护并发送自定义表情包。
- 转发帖子：帖子转发给关注的人后，对方可点击进入帖子详情。
- 关注限制：非互相关注用户私信次数受限，管理员和审核员沟通不受关注关系限制。
- 拉黑限制：拉黑后对方不能继续发送消息。
- 后台私信：举报管理、用户沟通和审核沟通可跳转站内私信。

 ### 8. 个人中心模块

个人中心用于展示用户资料、社区等级、动态和个人资产。

子功能：

- 个人资料：编辑昵称、头像、手机号、性别、年龄、地址和个性签名。
- 资料展示：其他用户访问主页时展示昵称、头像、等级、签名、关注、粉丝、获赞和收藏统计。
- 隐私设置：可控制关注、粉丝和部分个人资料是否对外展示。
- 黑名单管理：查看已拉黑用户并取消拉黑。
- 每日签到：签到增加经验值并展示等级进度。
- 每日任务：通过发帖、评论、购买游戏获得经验，带每日上限。
- 动态列表：展示用户发帖动态，并显示点赞数、收藏数和评论数。
- 拥有游戏：展示已购买游戏数量、账号价值和游戏列表。
- 我的收藏：区分收藏的帖子和收藏的新闻。
- 我的帖子：管理自己发布的帖子，支持查询、编辑、删除和审核拒绝后的申诉。
- 我的订单：查询订单、删除订单、继续支付、取消待支付订单和申请退款。

### 9. 站内通知模块

站内通知模块统一承载互动提醒、关注提醒和治理进度，是用户接收社区反馈与处理结果的集中入口。

子功能：

- 点赞通知：别人点赞我的帖子或评论后生成提醒。
- 回复通知：别人回复我的帖子或评论后生成提醒。
- @我的：评论区 @ 我时生成提醒。
- 关注通知：别人关注我后生成提醒。
- 举报进度：展示我提交的举报处理状态和审核回复。
- 评论跳转：点赞、回复和 @ 通知支持跳转到对应帖子或评论位置。
- 用户信息：通知中展示触发用户头像、昵称和等级标识。
- 已读状态：进入通知后可更新通知阅读状态。

### 10. AI 助手模块

AI 助手用于游戏攻略问答、社区内容理解和评论区自动回复。

子功能：

- AI 聊天：用户可在独立 AI 助手页面发起对话。
- 历史会话：可查看历史对话。
- 清空记录：支持清空当前聊天内容。
- 导出记录：支持导出聊天记录。
- 图片分析：支持上传图片给 AI 分析。
- 站内上下文：AI 可读取网站游戏、帖子、新闻等业务信息作为回答上下文。
- 评论区 @AI：用户在评论区 @AI 助手后，AI 自动回复评论。
- 专属身份：AI 助手使用专属头像，不显示普通用户等级。
- 模型配置：MiniMax API Key、网关和模型参数通过配置项维护，便于更换。

### 11. 支付模块
- 立即购买：单款游戏直接创建订单。
- 购物车结算：多款游戏批量结算，每款游戏生成对应订单。
- 支付宝沙箱：付费订单进入支付宝扫码支付。
- 二维码支付：前台展示订单号、游戏信息、金额和二维码。
- 支付查询：系统轮询或手动刷新支付状态。
- 超时处理：待支付订单可取消，避免长期占用状态。
- 免费游戏：免费游戏直接购买成功。
- 我的订单：用户查询订单、继续支付、取消订单、删除订单和申请退款。
- 退款申请：用户填写退款原因后提交后台审核。
- 退款审核：管理员或社区审核员同意或拒绝退款。
- 幂等控制：订单创建、支付查询和退款流程使用 Redis/Redisson 做并发控制。

### 12. 内容治理模块
- 评论举报：用户可举报帖子评论或新闻评论。
- 用户举报：在用户主页更多菜单中举报用户，可填写原因并上传图片证据。
- 举报进度：用户可在站内通知中查看举报处理状态和审核回复。
- 后台筛选：后台支持按状态、类型、被举报用户筛选举报记录。
- 举报详情：管理员/审核员可查看举报用户、被举报用户、内容、原因、证据和状态。
- 禁言处理：可设置自定义禁言天数，并支持解除禁言。
- 封禁处理：可封禁账号，支持临时封禁、永久封禁和解除封禁。
- 拒绝处理：审核员可拒绝举报，并填写拒绝原因。
- 惩罚通知：被禁言或封禁用户会收到通知，并可申诉。
- 私信沟通：举报管理可跳转私信，与用户沟通处理细节。

### 13. 后台管理员模块
- 后台首页：展示用户增长、热门帖子、分类占比、活跃度、销量、评论点赞热力图、年龄占比、新闻浏览量、好评率等图表。
- 图表导出：后台图表支持导出，方便运营留档。
- 用户管理：新增用户、社区审核员和管理员账号，管理用户状态和资料。
- 角色权限：通过角色和菜单维护后台访问权限。
- 游戏管理：维护游戏名称、类型、平台、开发商、发售日期、价格、折扣、价格标记、截图、视频和简介。
- 新闻管理：新增、编辑、删除新闻，查看新闻详情和评论区。
- 帖子管理：审核帖子、查看帖子详情、查看评论区、编辑或删除违规帖子、处理申诉。
- 举报管理：筛选、查看、禁言、封禁、解封、拒绝举报和私信用户。
- 订单管理：查询订单、按用户筛选订单、删除订单、处理退款申请。
- 日志管理：记录用户操作，支持按时间筛选、导出和清空指定时间段日志。
- 站内私信：管理员/审核员与用户或其他审核人员沟通，支持文字、图片、表情和表情包。

### 14. 社区审核员模块
- 审核员首页：展示关联游戏发帖数、帖子浏览量、各类游戏帖子点赞和收藏数、当月审核数和待审核数。
- 新闻管理权限：可维护新闻内容和查看新闻评论。
- 帖子管理权限：可审核帖子、查看帖子详情和评论区，并可像用户一样参与评论。
- 举报管理权限：可处理举报、禁言、封禁、拒绝处理和私信用户。
- 站内私信：可与用户沟通，也可与管理员沟通。
- 权限隔离：没有管理员的完整系统配置、角色管理和全部数据操作权限。

### 15. 文件模块
- 图片上传：支持头像、帖子图片、评论图片、新闻图片、游戏截图和举报证据。
- 视频上传：支持游戏视频和富文本中的本地视频。
- 大文件支持：后端上传大小配置已放宽，支持较大的视频文件。
- 资源访问：通过统一文件访问接口读取上传资源。
- 缩略图：为列表页、游戏详情预览和视频封面提供缩略图能力。
- 路径兼容：资源路径通过配置项管理，减少部署到不同电脑后的路径修改成本。

### 16. 缓存性能模块
- Redis 缓存：缓存榜单、热门游戏、热门社区、用户拥有游戏摘要、部分统计数据和消息辅助数据。
- Cache-Aside：读多写少数据采用旁路缓存模式，先读缓存，未命中再查 MySQL 并回填。
- 延迟双删：更新 MySQL 后删除缓存，并延迟再次删除，降低并发下脏读概率。
- 分布式锁：订单提交、支付查询、退款处理、购物车结算等场景使用 Redisson 锁。
- 数据库索引：为用户、订单、帖子、评论、游戏、举报和日志等高频查询字段维护索引。
- 懒加载：前端对富文本、ECharts、图片和视频采用按需加载思路，减少首屏压力。
- 图片优化：列表页优先使用缩略图，详情页再加载高清资源。

## 数据库设计概览

项目使用 MySQL 保存核心业务数据，`database/schema.sql` 提供公开版基础表结构，后端 `config` 包中的多个初始化器会在启动时补充新功能所需字段、表和索引。

核心实体包括：

- 账号与角色：`AdminUser`、`ModeratorUser`、`PlayerUser`、`LegacyUser`、`BaseAccount`、`AccountSequence`、`Role`、`Menu`、`RoleMenu`。
- 用户资料：`User`、`UserInfo`、`UserRelation`、`UserBlacklist`、`UserDailyTask`。
- 社区内容：`Post`、`Comment`、`News`、`NewsComment`、`BrowseHistory`。
- 游戏业务：`Game`、`GameRating`、`GameWishlist`、`GameCart`、`Order`。
- 社交通知：`Message`、`Notification`、`Report`。
- AI：`AiConversation`、`AiMessage`。
- 运营治理：`OperationLog`。

常见索引方向：

- 用户：用户名、手机号、昵称、角色、状态。
- 帖子：游戏 ID、审核状态、创建时间、话题、用户 ID。
- 评论：帖子 ID、父评论 ID、用户 ID、创建时间。
- 游戏：名称、类型、平台、开发商、价格、折扣、评分。
- 订单：订单号、用户 ID、游戏 ID、订单状态、退款状态、创建时间。
- 举报：状态、类型、举报人、被举报人、创建时间。
- 消息：发送人、接收人、会话、是否已读、创建时间。
- 通知：接收人、类型、是否已读、目标 ID、创建时间。

## 配置说明
- `server.port`：后端服务端口。
- `spring.datasource.url`：MySQL 地址和数据库名。
- `spring.datasource.username` / `spring.datasource.password`：数据库账号密码。
- `spring.redis.host` / `spring.redis.port` / `spring.redis.password`：Redis 连接信息。
- `file.upload-path`：上传文件保存目录。
- `spring.servlet.multipart.max-file-size`：单文件上传大小限制。
- `spring.servlet.multipart.max-request-size`：单次请求上传大小限制。
- `spring.mail.host` / `spring.mail.username` / `spring.mail.password`：找回密码邮件服务配置。
- `alipay.appid` / `alipay.privateKey` / `alipay.alipayPublicKey` / `alipay.notify-url`：支付宝沙箱支付配置。

## 快速启动

### 1. 初始化数据库

1. 创建数据库：

```sql
CREATE DATABASE gaming_db DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

2. 导入基础脚本：

```bash
mysql -u root -p gaming_db < D:\Game_Community\database\schema.sql
```

3. 启动后端后，项目会通过初始化器补齐新功能字段、表和索引。

### 2. 启动 Redis

Windows 本地示例：

```bash
D:\redis\redis-x64-5.0.14.1\redis-server.exe D:\redis\redis-x64-5.0.14.1\redis.conf
```

如果 Redis 地址、端口或密码不同，请同步修改 `application.yml` 或环境变量。

### 3. 启动后端

进入后端 Maven 根目录：

```bash
cd D:\Game_Community\game-community-website\game-community-website
mvn clean package
```

启动服务：

```bash
cd D:\Game_Community\game-community-website\game-community-website\base-server
mvn spring-boot:run
```

也可以在 IDE 中直接运行：

```text
com.sys.pro.CustomApplication
```

### 4. 启动前端

进入前端目录：

```bash
cd D:\Game_Community\base-web
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

- 支付链路真实：接入支付宝沙箱扫码支付，支持订单、购物车、退款和免费游戏特殊处理。

## 创新点

- AI 深度融入社区：AI 不只是独立聊天窗口，还能在评论区被 @ 后结合帖子上下文回复。
- 混合推荐策略：游戏列表和帖子基于协同过滤算法生成个性化推荐，冷启动或无行为数据时自动降级为销量×好评率的热度排序兜底；帖子推荐综合点赞、收藏、转发和新近度加权评分，保证推荐列表始终有内容可展示。
- 社区内容与游戏数据互相增强：热门游戏、热门社区、榜单、帖子和评价互相引用，提升内容发现效率。
- Steam 风格评价倾向：游戏评价不只用分数，还用推荐、不推荐和中评表达用户态度。
- 精细化好评率标签：按评价数量和好评率区间生成好评如潮、特别好评、褒贬不一等评价类型。
- 审核员角色独立：不是简单管理员降级，而是提供面向社区治理的独立后台工作台。
- 通知中心聚合：点赞、回复、@、关注和举报进度集中展示，且支持跳转到对应内容。
- 游戏榜单多维分析：从收入、好评率、愿望单、优惠、平台和类型多个角度观察游戏表现。
- 支付并发控制：使用 Redisson 分布式锁处理重复下单、支付查询和退款幂等问题。
- 媒体资源兼容：图片、视频、头像、评论图片、表情包和缩略图统一管理，适合迁移部署。
